# 自定义按钮控件实现计划

## 1. 控件结构设计
- 创建自定义控件类 `CustomButton`，继承自 `Avalonia.Controls.Button`
- 使用 `Grid` 布局实现左侧SVG图片区域和右侧文字区域的排列
- 基础样式：白色背景、30px圆角长方形

## 2. 依赖属性设计
- `SvgContent`：用于设置左侧显示的SVG内容
- `ButtonText`：用于设置右侧显示的文字
- `NormalBackgroundColor`：正常状态背景色
- `HoverBackgroundColor`：悬停状态背景色
- `PressedBackgroundColor`：按下状态背景色
- `DisabledBackgroundColor`：禁用状态背景色
- `NormalBorderColor`：正常状态边框色
- `HoverBorderColor`：悬停状态边框色
- `PressedBorderColor`：按下状态边框色
- `DisabledBorderColor`：禁用状态边框色
- `TextColor`：文字颜色
- `TextSize`：文字大小（默认25px）

## 3. 样式实现
- 使用Avalonia的样式系统定义不同状态的视觉效果
- 实现正常、悬停、按下、禁用状态的样式变化
- 使用 `Style` 和 `Setter` 定义状态样式
- 使用 `Trigger` 实现状态切换效果

## 4. 布局实现
- 使用 `Grid` 布局，左侧列宽自适应SVG内容，右侧列宽自适应文字内容
- 确保控件布局响应式，在不同尺寸下保持元素比例和位置关系
- 实现控件的命中测试，确保交互区域正确

- `g:\PCL.Neo\PCL.Neo\Controls\CustomButton.axaml`：控件的样式定义
- `g:\PCL.Neo\PCL.Neo\Controls\CustomButton.axaml.cs`：控件的C#代码-behind，包含依赖属性定义

## 6. 使用示例
- 在 `HomeView.axaml` 中添加自定义按钮控件的使用示例
- 演示不同状态下的控件效果

## 7. 状态变化效果
- 正常状态：默认样式显示
- 鼠标悬停：背景色和边框色变化
- 按下状态：背景色和边框色变化，控件轻微缩小
- 松开状态：恢复正常样式
- 禁用状态：背景色和边框色变化，文字颜色变化，不可交互
